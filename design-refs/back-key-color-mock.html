ABC 鍵的配色區分候選：主字 ABC ＋ 左上角小 ← · 2026-11-07

底行是「ABC / ASC / CJK / 空格 / ⏎」。ABC 是唯一的回頭鍵，值得和 ASC／CJK 拉開層次； 但 Enter 已經佔了實心強調色，ABC 不能跟它搶。

取捨總表

方案做法優點風險
V0 現狀與 ASC／CJK 同為 fn 底最整齊、最安靜回頭鍵與切頁鍵同權重，沒有指向性
V1 文字上色fn 底不變，ABC 與 ← 用強調色侵入最小，一眼看出「這顆不一樣」色弱或低亮度下差異偏弱
V2 描邊fn 底 ＋ 2px 強調色邊框 ＋ 強調色文字存在感明確，又不像實心那樣重與相鄰鍵只隔 13px，邊框易顯擁擠
V3 淡染底（推薦）強調色 16% 透明底 ＋ 強調色文字「這是主路徑」的直覺最強；深淺兩色都成立需在配色檔多一組 nav_* 顏色
V4 淡染＋細邊V3 再加 1.5px 低透明邊鍵形邊界更清楚細節多，和 V2 的差別肉眼幾乎分不出
V5 實心強調整鍵填強調色最醒目不建議：與 Enter 兩塊藍互相搶，底行重心散掉
V6 亮一階底色比 fn 亮一級不改色相，最保守「亮 = 回去」的語義不成立，等於只是換了灰
V7 暗一階底色比 fn 暗一級有「內凹／退回」的隱喻深色主題下幾乎看不出來
實現成本：V1／V2 不需改配色檔（直接內聯 key_text_color / key_back_color）； V3／V4 建議在 preset_color_schemes 增兩組 nav_back_color / nav_text_color，兩套配色各給一組值。
